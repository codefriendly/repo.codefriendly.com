Install from the binary repository

  1. Download and check the signing key

    Download the public key and display its fingerprint.

    curl -fSLo codefriendly-repo.asc https://repo.codefriendly.com/arch/codefriendly-repo.asc
gpg --show-keys --with-fingerprint codefriendly-repo.asc

    Check that the full fingerprint matches this value before continuing:

    AFA2 FD35 394F 39A7 61B7 83E5 7695 B10F 4DFB 18FE

  2. Trust the repository key

    Only do this if you trust CodeFriendly to provide software for your system.

    sudo pacman-key --add codefriendly-repo.asc
sudo pacman-key --lsign-key AFA2FD35394F39A761B783E57695B10F4DFB18FE

  3. Add the repository

    Add this block to /etc/pacman.conf, below your existing repositories.

    [codefriendly]
SigLevel = Required DatabaseRequired
Server = https://repo.codefriendly.com/arch/$arch

    Pacman checks both package and repository database signatures.

  4. Update and install

    Refresh the repositories, upgrade your system, and install cliamp.

    sudo pacman -Syu cliamp

    Debug packages are not hosted. You can build them locally from the packaging source if needed.
